# 地摊经济双边应用 · 领域调研简报

日期：2026-09-04  
对象：创始人（业务语言，不谈实现细节）  
范围：中国地摊 / 夜市 / 市集 / 外摆；摊主（B）+ 消费者（C）  
前提：找摊、摊位撮合、摊主经营工具都在范围内；内容社区低优先级。

## 1. 一句话结论

这个赛道值得做，但不能再做 2020 年那种「全国摊位地图」。

**产品定性（当日更正）：** 开摊不是限时市集。它是每天开门的固定经营场所，把原来散在路边、不合规的摊主收到一个点上规范经营。摊位按天报名，不报当天不保证有位。下面市集 / 夜市材料仍作参照，主循环按「进场 → 每日报名占位 → 今晚谁在」走。

## 3. 摊主真实工作流与痛点

按「高频且严重」排序。

1. **选得到合法点，不代表选得到能赚钱的点。** 郑州等地有疏导点，摊主仍觉得位置偏或摊位费过高，宁可继续游击。与多城记者走访一致。来源：[网易「三轮车之上」](https://c.m.163.com/news/a/L542P3OJ05198R91.html)
2. **市集报名像赌博。** 主办方海报夸客流，摊主重填表单、私信追进度、交了摊位费可能扑空。这是市集通 / 摆个市集 / 市集同行都在讲的同一句话。
3. **天气和客流把利润打穿。** 毛利常见 30–50%；日流水 2000 到手可能 550–750；下雨直接腰斩。普通小吃摊月净利多在 3000–8000，和打工重叠。自媒体测算，当量级看不要当精确数。来源：[头条「别再相信地摊月入三万」](https://www.toutiao.com/article/7628943352959943203/)
4. **获客仍靠微信群和朋友圈「今天出不出摊」。** 头部摊主线上能贡献约三成；普通人没有这个能力。
5. **城管 / 投诉 / 油烟噪声** 决定能不能留下来，不决定日销售额。食品摊还要健康证、净化设备。
6. **记账、进货、收款** 痛，但付费意愿低。1688 / 拼多多 / 个人收款码已经够用。平台代收合规重，早期不要碰。

愿意付钱的环节：摊位费本身（已经在付）、帮自己少报空、少填表、少被骗。不愿意付钱的环节：通用记账 SaaS、全国摊位热力图、内容社区。

## 4. 消费者怎么发现、卡在哪

发现路径：小红书 / 抖音探店 → 朋友圈定位 → 路过偶遇 → 大众点评夜市词 → 地图导航。决策看：今开不开、几点、卖什么、排不排队、卫不卫生、会不会踩雷。

真实痛点不是「缺少社交」，是 **跑空**。2024 年记者按网友「市集大全」跑上海 8 家，只逛到 1 家；官方「摊」地图和「上海之夏排片表」准但不全。2026 年「鬼市」笔记里第一坑仍是跑空。来源：[腾讯新闻「赶集踏空率太高」](https://news.qq.com/rain/a/20240710A07OJK00)

消费者要的是「市集排片表 + 今日开摊」，不是又一个点评社区。

## 5. 政策与合规红线（对产品的直接约束）

2020 年那波「全面放开」已经过去。2024–2026 的主旋律是疏导 + 规范 + 数字化备案，不是谁都能在路边支摊。

- 《无证无照经营查处办法》（国务院令第 684 号，2017）：只有在县级以上政府指定的场所和时间，卖农副产品 / 日用品或做便民劳务，才不算无照经营。食品摊不在这个豁免里。[食品伙伴网文本](https://news.foodmate.net/2017/08/440925.html)
- 上海：2023《关于进一步规范设摊经营活动的指导意见（试行）》划疏导点 / 管控点 / 特色点；2025《关于进一步优化设摊治理提升城市烟火气的工作方案》要求增设点位、夜市试点、信息对社会公开、鼓励线上场景。[上海城管](https://cgzf.sh.gov.cn/channel_8/20250620/9418115796ce4af591588194c80c965d.html)
- 杭州：外摆「七个不得」、须备案且有执照、业态与店内一致；「摊有序」预约 + 信用分。商业外摆不等于个人游击摊。[杭州政府](https://www.hangzhou.gov.cn/art/2025/7/4/art_812269_59114773.html)
- 食品摊：各省小作坊 / 小餐饮 / 小摊贩条例，健康证 + 食品经营许可或备案；夜市管理方通常要求挂证。
- 平台若做撮合 + 代收摊位费 / 货款：按网络交易平台走，要主体资质、食品责任边界、支付合规。MVP 只做信息与报名状态，不碰代收和担保。
- 小程序：交易类需要个体户 / 企业主体；个人主体几乎做不了经营性支付。先用企业主体做工具 / 本地生活类目。

对产品：只服务已在合法点 / 主办方场地里的摊，不给游击摊导航「躲避城管」。否则既违法，也和政府系统对立。

## 6. 谁在付钱、先赚谁的钱

已经有人付的钱：
- 摊位费：夜市月租几百到上千，市集按场次收；这是主办方的主营。
- 主办方为减少表单 / 对账 / 客服私讯付 SaaS（台湾案例清楚；大陆智慧市集厂商在卖给文旅 / 景区）。
- 海外对标的真利润在活动订餐抽成，不在 C 端广告。

几乎没人付的钱：
- 摊主订阅通用经营工具。
- 消费者为「找摊」付费。
- 纯内容社区。

新入场建议：第一年向主办方收钱（按场或按年，报名 / 审核 / 选位），摊主免费，消费者免费。平台抽摊位费要等信任和担保能力够了再做。

冷启动：不要拉全国摊主。签 3–5 个每周都办的市集 / 夜市，把他们现在的微信群 + 问卷星搬进来。C 端用「本周不会跑空的排片」获客。

## 7. 技术与平台（给拍板用）

推荐最小组合：
- 载体：微信小程序（摊主、主办方、消费者同一套；分享到群是获客通道）。
- 现在这一周：先做 Web 高保真原型，用浏览器把三端主循环跑通，再迁小程序。避免一上来卡在主体认证和审核。
- 地图：腾讯位置服务（和微信同生态）或高德；MVP 用列表 + 地址 + 导航外链即可。
- 支付：MVP 不做。摊位费继续微信转账 / 主办方自己收。接入支付再注册个体户 / 企业商户。
- 消息：小程序订阅消息做「审核通过 / 今日开摊」。
- 不做原生 App，不做出海。

## 8. 切入点与推荐排序

| 排序 | 切入点 | 循环 | 为什么现在 | 最大风险 |
| --- | --- | --- | --- | --- |
| 1（推荐） | 一城市集操作系统：主办方发场 → 摊主报名 → 消费者看排片 / 今日开摊 | 主办方少表单，摊主少跑空，消费者少扑空 | 钱已在摊位费里；上海跑空被报道；成都已有人做证明需求真实 | 签不到每周办的主办方 |
| 2 | 单点夜市数字化（一个商场 / 街区夜市） | 管理方管摊，摊主打卡，周边居民看今日菜单 | 杨浦太平洋广场一类夜市已在做人工版 | 做成项目制，难复制 |
| 3 | 摊主经营工具 | 收款 / 记账 / 预告 | 痛真实 | 付费意愿低，1688 / 微信已占位 |
| 4 | 全国摊位地图 | 摊主上图，消费者找附近 | 腾讯 2023 做过 | 供给腐烂、冷启动、政策敏感 |

不推荐一上来做内容社区、供应链、担保交易。

- 市集同行的 1000 用户 / 已盈利来自其官网，未独立核实。
- 摊主收入区间来自媒体和自媒体，不是抽样调查。
- 腾讯小摊地图「停更」是「2024 后无公开迭代」，不是官方宣布关闭。
- 未做主办方付费意愿的一手访谈；这是下一步该补的。
- 未覆盖进货供应链、品类差异的量化、下沉县城夜市。
