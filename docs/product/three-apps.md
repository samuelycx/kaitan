# 开摊 · 三端形态

日期：2026-09-04  
前提：经营点每天开门；摊位按天报名，不报当天没有位。  
依据：[调研简报](../research/2026-09-04-domain-brief.md)、汉中前进路夜市「整场入驻美团」报道、市监总局网络餐饮主体责任规定。

实际使用拆成 **三个小程序**，不共用一个入口切角色。心智不同：逛的人要「今晚吃什么」，摊主要「占到位、卖得出、收得到钱」，管场要「今晚场子站得住」。

企业主体可注册多个小程序（企业上限 50，个体户 5）。三个都挂同一主体，互相跳转。个人主体做不了经营性支付。

## C 端 · 开摊

心智：出门前就知道今晚这个点有什么好吃的；手机点好付好，到摊位取；可以转给朋友。

只展示 **今日占到摊位** 的摊。未报名的不出现。

点单不是所有摊的标配，只开放给 **证照办齐、愿意上线收款** 的商户：

1. **没证照**：小程序只展示（今晚在、卖什么）。点单和付款都在摊位上完成。C 端写清「到摊点、到摊付」。
2. **证照办齐**：可以上架菜品，开放小程序点单和付款，到摊取。办齐指出：个体户执照（或企业）+ 食品经营许可 + 自己的微信支付商户号。健康证、地方摊贩卡不够开点单。口头说愿意办、证还没下来，仍按第 1 档，不能收款。

便民摊（修伞等）永远第 1 档。食品摊要开点单，挂的是食品经营许可（须先有营业执照），不是只挂健康证或摊贩卡。浙江还写明摊贩不得从事网络食品经营。

有证摊的主路径：进点 → 今晚摊与招牌菜 → 进一个摊下单（一单一摊）→ 付款 → 取餐号 → 到摊取 → 分享。先做 **到店自取**，不做骑手外卖。

## B 端 · 开摊摊主（地摊版美团）

简单，只做今晚能卖钱的四件事：

1. **占位**：截止前报名今日摊位；不报没有位，C 端也不会上你。
2. **菜单**：所有占到位的摊都可以写「今晚卖什么」给 C 展示。只有证照办齐的摊，这些菜才能变成可点、可付。
3. **接单**：仅证照办齐的摊接线上单、出餐、叫号。
4. **收银**：没证的摊以摊位收款为主，B 端可记一笔现场单。有证的摊：线上单和现场单同一本今晚流水。

不做进货、复杂会员、全国店铺装修。摊主已经在付管理费，B 端免费。

## 管理端 · 开摊管场（规划）

管场在场子里走，用小程序，不做电脑后台当第一入口。

管的是 **今晚这场生意能不能开起来**，不是内容社区。

| 模块 | 管什么 | 不做 |
| --- | --- | --- |
| 场所 | 每天几点到几点、报名截止、总摊位、今日停市 | 全国多店集团中台 |
| 在册 | 路边摊迁入审核、从哪条马路来、证照两档（仅展示 / 点单已开通） | 替摊主办证、口头意愿就开点单 |
| 当日占位 | 已报、已占、候补、未报；到点截止；未到的位放给候补 | 月租占死摊位 |
| 今晚供给 | 预览 C 端会看到的摊和菜；点单开关只在证照核过之后打开 | 替摊主写文案 |
| 现场 | 谁占了位但没到；纠纷记一笔 | 城管执法 |
| 管理费 | 谁本月该缴、是否已缴（钱先线下收） | 平台代收摊位费（第一期） |
| 点单之后 | 退款仲裁、暂停某摊接单、当日流水总览 | 骑手调度 |
| 安全 | 无证食品摊禁止点单；订单留存（法规要求不少于三年） | 平台承诺食品安全 |

点单是可选项。没证的摊照样进场、占位、被 C 看到，买卖在摊上完成。只有商户把证办齐，管场核过，才打开上架和点单。开摊对已开通点单的摊，法规上接近网络餐饮第三方平台：审查证照、公示、能停摊、订单留三年。

## 钱怎么走

货款进 **摊主自己的商户号**。顾客付哪一摊，钱就进哪一摊。经营点不代收，平台不截留，也不再和摊主日结货款。

做法：开摊做微信支付 **服务商**，摊主做 **特约商户（子商户）**。官方规则就是「微信支付 → 子商户结算账户，服务商账户不直接收款」。订单、取餐号仍走开摊，对账不靠私聊转账。

到账：付款成功后摊主立刻在商家助手 / B 端看到这笔单。结算到银行卡，个体户餐饮官方默认 **T+1、费率约 0.6%**（微信支付结算规则，2026-06 更新）。不是默认秒到。要当晚能提到卡里，再单独开通秒到；现场现金 / 摊主自己的收款码仍记在当晚流水里。

第一年：向管场收场所服务费。摊主免费，C 免费。以后若抽点单佣金，用分账从摊主商户划一笔，不先把货款收到经营点再分。

退款从该摊主商户出。管场可以停某摊接单，不经手钱。

不做：用个人微信收款码冒充商户点单（查不到、退不了、留不住三年订单）；也不做经营点统一收款再日结（摊主看不见自己的钱）。

## 分期（不一次做成美团）

0. **现在**：Web 三栏演示占位。还不是三个小程序。
1. **下一周**：真实点上，用占位换掉群点名。同时让摊主填今晚菜单，C 端只看「今晚有什么」——仍不收款。
2. **有企业主体后**：三个小程序上架，同主体跳转，订阅消息做截止提醒 / 占到 / 取餐。
3. **摊主个体户 + 特约商户齐了**：C 点单付款到店取，钱进该摊商户号。

没有第 1 步，第 3 步是空中楼阁：菜单和占位对不上，点单没有今晚供给。
