# 开摊

每天开门的固定经营点：把原来散在路边的摊收到场内。不是周末市集。

浏览器里是三个小程序的原型：**顾客端 / 摊主端 / 管场端**。数据在各自浏览器里，互不影响。

## 自己跑

```bash
npm install
npm run dev
```

打开提示的本地地址。顶上三个按钮切换端。

- 顾客：看今晚占到位的摊，对着场图找，证齐的能点单到摊取
- 摊主：点空位抢位，先点先得；菜单、接单、收银
- 管场：今日占位、进场、核证、现场、流水

依据见 [调研简报](docs/research/2026-09-04-domain-brief.md) 和 [MVP 规格](docs/product/mvp-spec.md)。
